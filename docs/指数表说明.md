# 指数表（indices.db）说明

本文说明 `data/database/indices.db` 的用途、表结构、数据来源与同步逻辑。

---

## 一、做什么用的

`indices.db` 是系统的**指数目录表**，存"指数代码 → 名称 → 市场"的映射，用于：

- 对外接口 `GET /api/indices`（按代码/市场/名称查询指数）。
- 为其他模块提供指数清单（如指数K线、ETF跟踪标的名称对齐等）。

它**不是行情/成分数据**，只是一张**代码-名称列表**。

---

## 二、表结构

**`indices`**
| 字段 | 类型 | 说明 |
|---|---|---|
| `code` | TEXT | 指数代码（**去前缀/后缀**，如 `000001`、`399001`、`000300`、`931247`） |
| `name` | TEXT | 指数名称 |
| `market` | TEXT | 市场/后缀标识，见下 |
| `source` | TEXT | 数据来源：`codes` / `touzid` |
| `updated_at` | TEXT | 更新时间（RFC3339） |
| | | **主键：(code, market)** |

**`market` 取值**：
| 值 | 含义 |
|---|---|
| `sh` | 上证（沪市） |
| `sz` | 深证（深市） |
| `cs` | 中证（中证指数有限公司编制） |
| `cn` | 国证·跨市场 |
| `bj` | 北证 |
| `hk` | 港股（恒生/港股通） |
| `us` | 海外（美股，纳指/标普等） |
| `ms` | MSCI（明晟指数） |

> 注：`code` 与 `market` 组成主键，因为**同一 6 位代码在不同市场可能指不同指数**（如 `000001` 在 `sh` 是上证指数）。

---

## 三、数据来源（两个，可共存）

### 3.1 来源一：`codes` 自动同步（`source=codes`，程序启动时）

程序启动 `InitIndices()` 会**自动**从 `codes` 数据（通达信全市场码表）中提取**沪深指数**写入本表：

- 判定函数：`protocol.IsIndex()`。
- 覆盖号段：
  | 号段 | 含义 | 数量（约） |
  |---|---|---|
  | `sh000xxx` | 上证系列指数 | 200 |
  | `sh880xxx` / `sh881xxx` | 通达信板块/统计指数 | 1119 |
  | `sz399xxx` | 深证系列指数 | 354 |
- 写入时 `market = 交易所`（`sh`/`sz`），`code` 去前缀。
- 每次启动都同步一遍（`INSERT OR REPLACE`，幂等）。

### 3.2 来源二：投资数据网 xlsx 导入（`source=touzid`，手动）

**跨市场指数**（中证/国证/港股/海外/MSCI 等）不在通达信 `codes` 表里，需手动导入：

```bash
python scripts/import_indices.py --file /path/to/指数列表-加权平均值-3年.xlsx
```

- 数据源：投资数据网导出的 xlsx（523 个指数）。
- 脚本直接解析 xlsx 内部 XML（兼容 GBK 中文），跳过前 2 行表头。
- `code` 去 `.sh/.sz/.cs` 等后缀，后缀映射到 `market`。
- `source` 固定 `touzid`。
- **不 `DROP TABLE`**：改 `CREATE TABLE IF NOT EXISTS` + `INSERT OR REPLACE`，与 `source=codes` 的沪深指数**共存**。

## 四、逻辑流程

```text
┌─────────────────────────────────────────────────────────────┐
│ 程序启动 InitIndices() （在 codes 加载之后调用）              │
│   1. 打开 data/database/indices.db                           │
│   2. CREATE TABLE IF NOT EXISTS indices(...)                 │
│   3. indicesSyncFromCodes():                                 │
│        getAllCodeModels() 取全量代码                          │
│        for 每只: if IsIndex(fullCode):                       │
│             INSERT OR REPLACE (source=codes, market=sh/sz)   │
│      → 日志: "指数表已从codes同步 N 条(沪深指数)"             │
└─────────────────────────────────────────────────────────────┘
                          │
                          ▼
┌─────────────────────────────────────────────────────────────┐
│ 可选：手动导入扩展指数                                        │
│   python scripts/import_indices.py --file xxx.xlsx           │
│     → source=touzid 写入(不覆盖 codes 行)                    │
└─────────────────────────────────────────────────────────────┘
                          │
                          ▼
┌─────────────────────────────────────────────────────────────┐
│ 查询 GET /api/indices（纯查库,不联网,不触发抓取）            │
│   参数: code / market / search / limit / offset              │
│   返回: { total, count, list:[{code,name,market,source}],    │
│           limit, offset }                                    │
└─────────────────────────────────────────────────────────────┘
```

## 五、相关接口

### `GET /api/indices`

| 参数 | 类型 | 说明 |
|---|---|---|
| code | string | 指数代码（去后缀），支持逗号分隔多个 |
| market | string | 市场过滤，支持逗号分隔多个（如 `sh,sz`） |
| search | string | 按名称模糊搜索 |
| limit | int | 返回条数，默认 100，最大 1000 |
| offset | int | 偏移量，默认 0 |

**示例**：
```
GET /api/indices?code=000300
GET /api/indices?market=sh,sz
GET /api/indices?search=沪深300
```

---

## 六、注意点

1. **纯目录表**：只有代码/名称/市场，无行情、无成分股。
2. **两来源可共存**：`source=codes`（沪深，自动）+ `source=touzid`（跨市场，手动）。
3. **同一 `(code,market)` 会互相覆盖**：若沪深指数两边都有（如 `000300 sh`），后写入的覆盖前者（内容一致，无影响）。
4. **自动同步是幂等的**：重启不会重复堆积，只刷新 `updated_at`。
5. **xlsx 导入不再清表**：改版后手动导入只增补跨市场指数，不删已有数据。
6. `source` 字段可用来区分"自动同步"还是"手动导入"的数据。
