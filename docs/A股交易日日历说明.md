# A股交易日（工作日）日历说明

本文说明 `data/database/workday.db` 的作用、数据来源、判断逻辑与用途。

---

## 一、做什么用的

`workday.db` 是系统的 **A股交易日历**，回答一个问题：**某一天是不是开市交易日？**

被用于：
- 历史分时成交遍历（`/api/trade-history-full` 等按交易日逐日拉数据）。
- K线/入库任务判断"某天有没有数据"。
- 对外接口 `/api/workday`、`/api/workday/range`。

---

## 二、表结构

**`workday`**
| 字段 | 类型 | 说明 |
|---|---|---|
| ID | int64 | 主键，自增 |
| Unix | int64 | 交易日 0 点时间戳 |
| Date | string | 日期 `YYYYMMDD` |

- 现值约 **8724 行**，从 **1990-12-19**（上交所成立）至今的每个交易日一条。
- 天数自动维护（见第四节）。

---

## 三、数据来源

**依据 = 上证指数 `sh000001` 的日K线。**

- 逻辑：**有日K线的日期就是交易日**（指数不开市就没有K线，天然排除周末和节假日）。
- 拉取方式：`Client.GetIndexDayAll("sh000001")` 取上证指数全部日K线。
- 不需另外维护交易日表，也没用第三方节假日接口——**完全以上证指数实际开市日为准**。

---

## 四、更新逻辑

### 4.1 更新时机

- 服务启动时：`NewWorkday()` 里先调一次 `Update()`。
- 之后每天 **早上 9:00** 定时更新（cron）。
- 失败重试 3 次，每次间隔 5 分钟。

> 注：注释明确"8点多获取不到今天的数据"，所以定在 9:00。

### 4.2 增量更新（`Update()`）

```text
1. 读 workday 表全部记录 → 找出最后一条 lastWorkday
     同时把已有日期灌入内存位图 cache
2. 若 lastWorkday 的日期 < 今天:
      拉 sh000001 全部日K线
      对 K线时间 > lastWorkday 的每一条:
           追加 WorkdayModel{Unix, Date} 到 insert 列表
           同时写 cache
      批量入库（增量,不重复）
3. 若已是最新: 什么都不做
```

**特点**：
- **增量**：只补晚于库里最后一天的日期，不重复写。
- **幂等**：多次调用安全。
- **动态**：新交易日出来后，下次更新自动追加。

---

## 五、判断"是否交易日"（`Is(t)`）

采用**三级回退**，优先级从高到低：

```text
Is(t):
1. 查内存 cache（来自上证指数K线）
     命中 → 是交易日 ✅
2. 回退：周六/周日 → 非交易日 ❌
3. 回退：命中内置 chineseHolidays 法定节假日列表 → 非交易日 ❌
4. 其余（周一至周五）→ 视为交易日 ✅
```

**要点**：
- **首选 K线缓存**最准（真实开市日）。
- **回退逻辑**用于"未来日期"（还没有K线了，靠日历推断）和历史缺数据兜底。
- **`chineseHolidays` 是硬编码的**，当前含 2025、2026 两年（元旦/春节/清明/五一/端午/国庆等）。**2027 年及以后需手动补**，否则法定节假日会被误判为交易日。

### 相关辅助方法

| 方法 | 说明 |
|---|---|
| `Is(t)` | 某天是否交易日 |
| `TodayIs()` | 今天是否交易日 |
| `Range(start, end, f)` | 正序遍历 [start,end) 内交易日，`f` 返回 false 终止 |
| `RangeYear(year, f)` | 遍历某年所有交易日 |
| `RangeDesc(f)` | 从今天倒序到 1990-12-19 |

> `Range` 推荐 `start` 带 `15:00`：这样"当天小于15点不会触发"，避免把当天（数据未出）算进去。

## 六、相关接口

### `GET /api/workday`
查某天是否交易日 + 前后 N 个交易日。

| 参数 | 说明 |
|---|---|
| date | 目标日期 `YYYYMMDD` 或 `YYYY-MM-DD`，默认今天 |
| count | 前后各取几个交易日，默认1，范围1-30 |

返回：`is_workday` + `next`（后N个交易日）+ `previous`（前N个交易日）。

### `GET /api/workday/range`
查日期范围内的交易日列表。

| 参数 | 说明 |
|---|---|
| start | 起始日期（必填） |
| end | 结束日期（必填） |

---

## 七、注意点

1. **当天（盘中）可能判不出**：数据库靠当天K线落库才认定，盘中K线未出时，`Is(今天)` 走回退逻辑（周一至五非节假日→按"是交易日"）。收盘出K线后由定时任务补入库。
2. **节假日列表要维护**：`chineseHolidays` 硬编码，跨年需补，否则未来日期的节假日判断会错。
3. **数据只增不改**：交易日只会追加，不会删除（除非停市）。
4. **依赖上证指数K线**：极端情况（上证指数数据异常）会影响更新，但已有历史数据仍在库。
